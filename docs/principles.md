# 框架原则

规矩(CLAUDE.md 铁律、各闸门)是**做法**;这里是做法背后的**原则**。规矩和 hook 注释里引用的
「派生 > 存储」这类说法,出处都在这一页。每条都附一个它为什么存在的教训(已去掉项目细节)。

---

## 1. 派生 > 存储

**能现算的状态就别存下来。** 存下来的状态没人保证它跟事实同步,而且读的人会当真。

- 文档里写「零代码」,主干上已经有几十个源文件 —— 每个塔开局都读那句当真。
  → 开局 hook 每次 `git ls-files` 现数(`session-start.mjs`)。
- 文档里写死某份设计「多少行」,后来它长了一倍 —— 工人照着给了一整节对不上的行号。
  → 写进仓库的每个数,要么现数,要么附上「怎么现数」那条命令。
- 压缩窗口写死在闸门里,改了设置之后闸门还按旧数拦。
  → 闸门9 从 `.claude/settings.json` 现读 `autoCompactWindow`。
- 例程提示词里写死会话 ID,会话一换全哑。→ 写「去活表查」。

**同一个病,同一页纸上能犯两次。** 改完一处,顺手搜一遍同类写法。

## 2. 信号长得像好消息的时候最该查

**看起来像「好了」的信号,是最容易漏查的。** 越像好消息越要自己去核。

| 看起来像 | 实际可能是 | 该查什么 |
|---|---|---|
| 会话状态 `IDLE` | 工人卡住了、在等人点、半路出错 | `list_sessions` + GitHub 上真有没有 PR / CI |
| 工人自述「全部完成」 | 没推、推错分支、测试没跑 | PR diff、CI 在最新提交上的结果 |
| CI 绿 | 测试没覆盖到这次改的东西 | 变异验证(见 `testing.md`) |
| 台账写着「已合」 | 没合、合的是别的 | `git log origin/main` 里找得到才算(闸门6) |

## 3. 派发权收归执行方

**立号、写任务书、派工人、收活,只能是那件活所属板块的塔自己干。** 别的塔可以建议,不能替它立号。

- 教训:中枢塔自己挑了一件活立号派出去,又顺手替开发板块写了一行任务 —— 用户问「这是谁创建的,我说过吗」。
- 原则早写在规矩里,**照抄了说法、没照抄做法**,于是原样复发了一次。→ 上了闸门4 / 闸门10 硬问。

配套:**「用户点头」看的是那句话存不存在、查不查得到,不是对谁说的。**
用户在别的塔说了「照这个做」、原话落进了台账 = 算;塔自己想出来的、别的塔口头转告但台账里找不到原话 = 不算。

## 4. 靠记性 = 必漏

**两步里的后半步靠人记得做,就一定会有人忘。** 要么让机器做,要么在收尾时拦一次。

- 台账推成了分支、没开 PR 合进主干 → 别的塔读不到。→ 闸门12 收尾拦。
- 改了 harness 没合进主干就说「各塔同步一下」→ 传的是空气。→ 闸门8 收尾拦。
- 塔的身份只活在开局那句口令里,压缩之后摘要未必还带着 → 塔忘了自己是塔。→ 开局 hook 从会话 ID 现查活表。

## 5. 确认闸,不是禁令

**敏感数据默认不进库,每次要进先问用户。** 真实数据往往是唯一的验证素材,迟早要用;
规矩不是「不许用」,是「不许自动流进来」。要用哪一份、脱敏到什么程度、进不进版本库,逐次问。

- 教训:一个外部工具目录被整个 `git init` 推进了仓库,里面绝大多数文件是别人的真实资料,没人问过就上了远端。
  事后只能用干净历史重建仓库。

## 6. 未实测的不当定稿依赖

「平台能不能做 X」这类断言,当场研究加实测;测不了的显式标 **[未实测]**。
文档写着「能」、实测「不能」的例子不少(见 `platform-facts.md`)。
从别的项目搬来的结论,在那边实测过 ≠ 在这边实测过。

## 7. 说「完成」前贴证据

可测量的断言要么附一条今天真能跑出那个数的命令,要么删掉。没有输出就不是完成,是「我以为」。

## 8. 闸门自己坏了不许瘫痪工作(fail-open)

hook 读不了输入、配置写坏、正则编译失败 → **放行**,不崩。闸门是提醒和兜底,不是单点故障。
软闸(提醒一次、原样再来就放行)优先于硬闸;硬闸只留给「做了撤不回」的事。

## 9. 塔讨论,工人干活

塔的上下文大,在塔里每走一步都比工人贵几倍。**塔:讨论 → 定 → 派 → 收。成品活派工人。**
教训:一个塔跑着跑着忘了自己是塔,两周没派过一个工人,上下文胖到了窗口的一半以上。

## 10. 说了要做的,一次做完再汇报

报了「我按五步做」然后做完第一步就回来 = 把交付换成了进度播报。
中途只在**真被挡住**时停(要拍板、要凭据、要外部的东西),停的时候说清卡在哪、需要什么。
